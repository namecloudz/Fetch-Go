fetch-go — drop axios, keep the API

An HTTP client that wraps native fetch() with the Axios interface you already know. Interceptors, retry, timeout, auto-JSON — all in ~3KB.

Migrate in one line

Swap the import. Everything else stays the same.

// before
- import axios from 'axios';
- const api = axios.create({ baseURL: 'https://api.example.com' });

// after
+ import fetchgo from 'fetch-go';
+ const api = fetchgo.create({ baseURL: 'https://api.example.com' });

// your code doesn't change
const { data } = await api.get('/users');
const { data: created } = await api.post('/users', { name: 'Jane' });

Quick start

If you've used Axios, this will feel familiar.

Error handling
import fetchgo from 'fetch-go';

// GET — response is auto-parsed from JSON
const { data } = await fetchgo.get('/api/users');

// POST — body is auto-serialized
const { data: user } = await fetchgo.post('/api/users', {
  name: 'John',
  email: 'john@example.com'
});

// TypeScript generics work as expected
const { data: users } = await fetchgo.get<User[]>('/api/users');
const api = fetchgo.create({
  baseURL: 'https://api.example.com',
  timeout: 5000,
  headers: {
    'Authorization': 'Bearer your-token'
  }
});

// all requests through `api` inherit the config above
const { data } = await api.get('/protected/resource');
// runs before every request
api.interceptors.request.use((config) => {
  config.headers['X-Request-ID'] = crypto.randomUUID();
  return config;
});

// runs after every response
api.interceptors.response.use(
  (response) => {
    console.log(`[${response.status}]`, response.config.url);
    return response;
  },
  (error) => {
    if (error.status === 401) window.location.href = '/login';
    throw error;
  }
);
// simple
await fetchgo.get('/flaky', { retry: 3 });

// with options
await fetchgo.get('/flaky', {
  retry: {
    retries: 5,
    delay: 500,              // 500ms then 1s, 2s, 4s, 8s
    backoff: 2,
    retryStatusCodes: [429, 500, 502, 503]
  }
});
import { FetchGoError, isCancel } from 'fetch-go';

try {
  await api.get('/might-fail');
} catch (error) {
  if (isCancel(error)) {
    console.log('cancelled');
  } else if (error instanceof FetchGoError) {
    console.log(error.status);              // 404
    console.log(error.response?.data);       // { message: "Not Found" }
    console.log(error.code);                // "ERR_BAD_REQUEST"
  }
}

What you get

Native fetch() under the hood

No XMLHttpRequest, no polyfills. Just the platform API with a better interface on top.

Request & response interceptors

Same Axios API — use() and eject(). LIFO for requests, FIFO for responses.

Built-in retry with backoff

Exponential backoff, configurable per-status-code. Pass a number or a config object.

Timeout & cancellation

Uses native AbortSignal — no deprecated CancelToken pattern.

TypeScript generics

fetchgo.get<User[]>('/users') — typed responses without type assertions.

Auto everything

JSON serialize/parse, Content-Type headers, error on 4xx/5xx — all automatic.
