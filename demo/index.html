⚡

Native Fetch

Built on the platform's native fetch() API. No XMLHttpRequest legacy. No polyfills needed.

🔄

Interceptors

Request & response interceptors with the same API you know from Axios. LIFO for requests, FIFO for responses.

🔁

Built-in Retry

Exponential backoff, configurable status codes, method filtering. No plugins needed.

⏱️

Timeout & Cancel

Native AbortSignal for both timeout and cancellation. No deprecated CancelToken.

🎯

TypeScript-First

Full generic support. Get typed responses with fetchgo.get<User[]>('/users')

🔧

Auto Everything

Auto JSON serialize request body. Auto parse response. Auto Content-Type. Auto error on 4xx/5xx.

Familiar API, Modern Engine

If you know Axios, you already know Fetch-Go

Simple GET 
import fetchgo from 'fetch-go';

// Auto-parses JSON ✨
const { data } = await fetchgo.get('/api/users');

// Full TypeScript generics
const { data: users } =
  await fetchgo.get<User[]>('/api/users');
POST with Body 
// Auto JSON.stringify + Content-Type
const { data } = await fetchgo.post(
  '/api/users',
  {
    name: 'John',
    email: 'john@example.com'
  }
);
Create Instance 
const api = fetchgo.create({
  baseURL: 'https://api.example.com',
  timeout: 5000,
  headers: {
    'Authorization': 'Bearer token'
  }
});

const { data } = await api.get('/users');
Interceptors + Retry 
// Add auth header to all requests
api.interceptors.request.use((config) => {
  config.headers['X-ID'] = crypto.randomUUID();
  return config;
});

// Retry with exponential backoff
await api.get('/flaky', {
  retry: { retries: 3, delay: 500 }
});
Migrating from Axios — Just change one line 
// Before (Axios)
- import axios from 'axios';
- const api = axios.create({ baseURL: '...' });

// After (Fetch-Go) — same API!
+ import fetchgo from 'fetch-go';
+ const api = fetchgo.create({ baseURL: '...' });

// Everything else works the same ✨
const { data } = await api.get('/users');
const { data: created } = await api.post('/users', { name: 'Jane' });
